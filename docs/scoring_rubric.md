# 就活比較スコアリング基準

各項目は5点満点です。初期スコアは公開情報を精査する前の仮説であり、IR、採用ページ、人的資本開示、口コミ、選考体験記を確認したら更新します。

## スコア項目

| 項目 | 見る内容 |
|---|---|
| industry_growth_score | 業界全体の成長性、需要の強さ、構造変化の追い風 |
| company_strength_score | 業界内の競争力、ブランド、収益力、事業ポートフォリオ |
| stability_score | 事業基盤、財務安定性、景気耐性、社会インフラ性 |
| compensation_score | 給与水準、賞与、若手待遇、成果報酬の強さ |
| career_capital_score | 転職市場での評価、専門性、汎用スキル、社外で通用する経験 |
| new_grad_access_score | 新卒採用の門戸、採用人数、職種の広さ、28卒マイページ確認状況 |
| culture_clarity_score | 社風・働き方・評価制度の情報が調べやすいか |
| work_life_balance_score | 労働時間、勤務地、リモート可否、休暇、働き続けやすさの見込み |
| transferability_score | 他社・他業界へ移る時の市場価値 |
| disclosure_score | IR、統合報告書、人的資本、採用情報の開示の厚さ |
| comparison_value_score | 同業他社比較に入れる価値。業界代表性、社風差、選考対策上の重要性 |

## 総合点

総合点は次の重みで計算します。

| 項目 | 重み |
|---|---:|
| industry_growth_score | 10% |
| company_strength_score | 13% |
| stability_score | 10% |
| compensation_score | 10% |
| career_capital_score | 13% |
| new_grad_access_score | 10% |
| culture_clarity_score | 7% |
| work_life_balance_score | 7% |
| transferability_score | 10% |
| disclosure_score | 5% |
| comparison_value_score | 5% |

## 点数の意味

| 点 | 意味 |
|---:|---|
| 5 | 非常に強い。業界内でも明確に優位 |
| 4 | 強い。志望先として十分に比較優位がある |
| 3 | 標準。魅力はあるが他項目との総合判断が必要 |
| 2 | 弱め。リスクや制約を確認したい |
| 1 | 現時点では優先度が低い、または根拠不足 |

## 注意

このスコアは就活の意思決定を助けるための比較用です。企業の絶対的な良し悪しではありません。希望職種、勤務地、専攻、価値観によって最適解は変わります。
