# 個人データベース連携モデル

このDBの最終目標は、共通の企業研究データベースと、就活生本人が入力する個人データベースを組み合わせて、次の2つを判断しやすくすることです。

- 内定しやすい企業
- 相性がいい企業

## データの分け方

### 共通DB

全ユーザーに共通する企業側の情報です。

- 業界
- 企業名
- 財務・成長性
- 採用情報
- 28卒マイページ状況
- 社風
- 働き方
- 待遇
- 転職市場価値
- 比較優位
- 懸念点

### 個人DB

就活生本人だけが入力する情報です。

- MBTIタイプ
- MBTIへの納得度
- 外向志向
- 変化耐性
- チーム志向
- 裁量志向
- 論理重視
- 計画志向
- ES・自己PR・ガクチカ
- 経歴・スキル
- 希望条件・制約
- 志望度
- スキル適合
- 社風適合
- 勤務地適合
- 職種適合
- 専攻適合
- 働き方適合
- 年収志向適合
- 海外志向適合
- 自己PR強度
- 応募ステータス
- 次アクション
- 締切
- 個人メモ
- 企業ごとのイベント・締切
- スコア根拠ソース

## スコアの考え方

### あなた向けスコア

企業の客観スコアに、志向プリセットと個人相性を掛け合わせたスコアです。

```text
あなた向けスコア =
  志向プリセットで重み付けした企業スコア * 0.46
  + 個人相性スコア * 0.20
  + 内定しやすさスコア * 0.16
  + 志望動機の作りやすさ * 0.10
  + ES素材適合度 * 0.08
```

### 内定しやすさ

現時点では次の仮説で算出します。

- 新卒採用アクセス
- 情報の集めやすさ
- 28卒マイページ確認状況
- スキル適合
- 職種適合
- 専攻適合
- 働き方適合
- 年収志向適合
- 海外志向適合
- 自己PR強度
- 応募ステータスの進捗

### 相性

本人入力を中心に算出します。

- 志望度
- スキル適合
- 社風適合
- 勤務地適合
- 職種適合
- 専攻適合
- 働き方適合
- 年収志向適合
- 海外志向適合
- 自己PR強度

MBTIは採用可能性の直接根拠にはしません。相性スコアの補助特徴量として弱めに反映します。

```text
相性スコア =
  企業別の個人入力 * 92%
  + MBTI・自己認識から見た社風補助相性 * 8%
```

MBTIは、次のように働き方・社風の好みに変換して扱います。

| MBTI要素 | 補助的に見る観点 |
|---|---|
| 外向/内向 | 顧客接点、チーム頻度、対人負荷 |
| 直感/感覚 | 新規性、抽象課題、変化耐性 |
| 思考/感情 | 論理・数値重視か、人間関係・共感重視か |
| 判断/知覚 | 計画的環境か、変化の多い環境か |

短絡的に「このタイプだからこの業界」とは判定しません。

## 志向プリセット

現在のプリセットは次の7種類です。

- 総合バランス
- 高年収重視
- 成長環境重視
- 安定重視
- ワークライフバランス重視
- 理系技術職向け
- 文系総合職向け

## 今後追加すると強い項目

- ES通過率
- Webテスト形式
- 面接回数
- OB/OG訪問の有無
- インターン参加実績
- 選考優遇の有無
- 自分のガクチカ・研究内容・資格との接続度
- 過去の選考ログ

これらが入ると、内定しやすさスコアはより実態に近づきます。

## AI分析フロー

現在の可視化UIでは、外部AI APIなしで動くローカル分析として次の流れを実装しています。

```text
応募者DB
  ↓
ES・経歴・希望条件から強み、スキル、希望、制約を抽出
  ↓
企業DB・採用傾向・根拠ソースと照合
  ↓
企業ごとに
  - あなた向けスコア
  - 内定しやすさ
  - 相性
  - 志望動機の作りやすさ
  - ES素材適合度
  - 注意点
  - 次アクション
を算出
  ↓
応募優先順位として提示
```

将来的にAI APIへ接続する場合も、この入出力構造をそのまま使えます。
